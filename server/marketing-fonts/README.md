# ELEVAY static-design fallback font

On 2026-10-04, Mahmoud Saber explicitly approved **Plus Jakarta Sans** as the disclosed fallback where the ELEVAY Design System calls for Apex Sans. This is **not** a claim that Apex Sans has been supplied. Do not silently substitute any other font.

The bundled Regular and Bold TTF files come from the [Tokotype Plus Jakarta Sans project](https://github.com/tokotype/PlusJakartaSans) and are licensed under the accompanying [SIL Open Font License 1.1](OFL.txt). The production build copies these hash-verified files into `dist/marketing-fonts/` for deterministic text composition; it does not expose font or credential data through a public API.

This font approval **does not release** image/video generation, publication, Meta changes or spending. Finished ELEVAY previews still require the official logo, English-only visual text on statics, no reel text, individually reviewed output, and the separate governed provider/quality gates.
